# Tests

Hardware validation records for the v1.0.0 reference image.

## Available Test Records

- `uart.md` — UART2 console validation
- `pcie.md` — PCIe validation
- `wifi.md` — Intel AX210 validation
- `usb.md` — USB 2.0/3.0 validation

These records describe tests performed on physical hardware. They are validation records, not automated hardware tests.
