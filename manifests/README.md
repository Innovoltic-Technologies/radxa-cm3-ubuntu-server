# Manifests

This directory records the contents and provenance of the v1.0.0 reference release.

## SHA256SUMS

`SHA256SUMS` contains checksums for source and board-specific files committed to the repository.

The complete release artifact checksum, including the disk image, is maintained separately under `release/SHA256SUMS`.

## Release Manifest

`release-v1.0.0.txt` records the components and versions associated with the v1.0.0 image.

## Third-Party Components

Third-party software and firmware retain their upstream licenses and provenance. This repository does not relicense those components.
